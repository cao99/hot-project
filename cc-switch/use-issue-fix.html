```html 问题总结
Claude Desktop × DeepSeek 问题总结

2026-05-29
遇到的问题
API Error: 400

在 Claude Desktop 中通过 cc-switch 接入 DeepSeek 模型执行任务时，每当对话涉及工具调用（MCP 工具、文件读写等 Agent 操作），就会报错：

The `content[].thinking` in the thinking mode must be passed back to the API.

根本原因

cc-switch 默认使用 Anthropic 原生接口（https://api.deepseek.com/anthropic）。Claude Code 在多轮对话中要求把上一轮的 content[].thinking 块完整回传，而 DeepSeek 使用的是 reasoning_content 字段，两套协议不兼容。一旦触发工具调用，thinking block 无法正确透传，API 即报 400 错误。

最终解决方案
1
修改请求地址
在 cc-switch 供应商编辑页面，将请求地址从
https://api.deepseek.com/anthropic
改为
https://api.deepseek.com/v1
2
切换 API 格式
将 API 格式从 Anthropic Messages（原生） 改为 OpenAI Chat Completions（需开启路由），通过 cc-switch 路由层做协议转换，彻底绕开 thinking block 回传机制。
结果
✅
切换为 OpenAI 兼容接口后，工具调用正常执行，不再触发 400 错误，Claude Desktop + DeepSeek Agent 任务恢复正常。
```
